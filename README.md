# vibevoice-api

This project is inspired by [Microsoft's VibeVoice](https://github.com/microsoft/VibeVoice), a family of open-source frontier voice AI models that includes both Text-to-Speech (TTS) and Automatic Speech Recognition (ASR) models.

## About

VibeVoice-API is an API implementation based on the concepts and technologies from Microsoft's VibeVoice project. The original VibeVoice uses continuous speech tokenizers operating at an ultra-low frame rate of 7.5 Hz and employs a next-token diffusion framework for high-quality voice synthesis and recognition.
