🎯 SCHNELLSTART FÜR INTEL NUC
══════════════════════════════

1. Archiv entpacken:
   tar -xzf vibevoice-api-cpu-optimized.tar.gz
   cd vibevoice-api

2. Start Script ausführen:
   ./start-cpu.sh
   
   Oder mit Make:
   make cpu-up

3. Warte 10-15 Minuten beim ersten Start
   (Modell wird heruntergeladen und geladen)

4. Teste:
   curl http://localhost:8000/health


⚡ WICHTIGSTE BEFEHLE
═════════════════════

make cpu-up        - API starten (CPU-optimiert)
make cpu-logs      - Logs anzeigen
make cpu-down      - API stoppen
make cpu-restart   - API neu starten
make cpu-stats     - Ressourcen überwachen
make test          - Beispiel Client ausführen


🔧 KONFIGURATION
═════════════════

CPU-Only:     FORCE_CPU=true
RAM Limit:    20GB
CPU Kerne:    8

              VibeVoice-7B (besser)
